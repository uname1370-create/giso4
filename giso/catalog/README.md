# کاتالوگ محصولات فروشگاه (داده ورودی)

این پوشه داده‌های آمادهٔ ورود محصول به فروشگاه گیسو را نگه می‌دارد.

- `لیست_۳۰_محصول_آماده_ورود.xlsx` / `.csv` — ۳۰ قلم منتخب از فهرست تأمین:
  - **۱۵ آرایشی/بهداشتی** → فروش مستقیم فروشگاه (`publish_status=published`).
  - **۱۵ خوراکی/تغذیه** → فقط سفارش خاص با توصیهٔ هوش مصنوعی در برنامهٔ تغذیهٔ زیبایی (`publish_status=special_order`، در فروشگاه عمومی نمایش داده نمی‌شود).
  - ستون‌ها: گروه، نام، قیمت فاکتور، **قیمت فروش = فاکتور × ۱.۵ رند به ۱۰هزار**، دسته، برچسب تطبیق (`concerns`)، توضیح.

## مسیر وارد کردن محصولات
۱. از طریق **کانال بله فروشگاه**: عکس + متن تمیز پست شود → ایمپورتر هوشمند (`channel_importer.py`) می‌سازد → ادمین ✅ منتشر می‌کند.
۲. از طریق **کاتالوگ تأمین** (فاز بعدی، پنل سوپر ← فروشگاه ← کاتالوگ هوشمند): آپلود فایل + تشخیص دسته با AI + محاسبهٔ خودکار قیمت فروش.

قیمت فاکتور (`cost_price`) داخلی است و هیچ‌جا به مشتری نشان داده نمی‌شود.
