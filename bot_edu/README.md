# 🎓 ربات آموزشی صادقی (sadeghy_edubot)

ربات آموزشی چندپلتفرمی روی **بله** و **تلگرام** — دوره‌های آموزشی، سیستم امتیاز و رتبه، ماموریت، گنجینه، فروش نقدی و مرکز پیام‌رسانی.

> 📘 **مستندات کامل توسعه:** فایل [`GUIDE.md`](GUIDE.md) را بخوانید (۲۰۷۵ خط — مرجع اصلی پروژه).

---

## ⚡ راه‌اندازی سریع (۴ قدم)

### ۱. دانلود پروژه

```bash
git clone -b arena/019f9dae-bot-edu https://github.com/uname1370-create/bot-Edu.git
cd bot-Edu
```

یا فایل ZIP را از گیت‌هاب دانلود و از حالت فشرده خارج کنید.

### ۲. نصب پیش‌نیازها

```bash
pip install -r requirements.txt
```

> ⚠️ **پایتون ۳.۱۱ یا ۳.۱۲ استفاده کنید.** پایتون ۳.۱۴ با `python-telegram-bot==20.7` سازگار **نیست**.
> ```bash
> py -3.11 -m pip install -r requirements.txt   # ویندوز
> python3.11 -m pip install -r requirements.txt # لینوکس
> ```

### ۳. ساخت فایل `.env` (مهم‌ترین قدم ⚠️)

فایل `.env` به‌دلایل امنیتی در گیت‌هاب **نیست** و باید خودتان بسازید:

```bash
cp .env.example .env      # لینوکس / مک
copy .env.example .env    # ویندوز
```

سپس `.env` را با Notepad یا هر ویرایشگری باز کنید و توکن را بگذارید:

```ini
BOT_TOKEN=1453074390:توکن_کامل_شما_اینجا
ADMIN_IDS=1191639507
SUPPORT_GROUP=@edu_work
BOT_USERNAME=sadeghy_edubot
DB_PATH=data/bot.db
```

| متغیر | الزامی؟ | توضیح |
|---|---|---|
| `BOT_TOKEN` | ✅ **بله** | توکن ربات بله (از @BotFather بله) |
| `ADMIN_IDS` | خیر | آیدی عددی ادمین‌ها — چند تا با کاما: `111,222` |
| `SUPPORT_GROUP` | خیر | آیدی گروه پشتیبانی |
| `BOT_USERNAME` | خیر | نام کاربری ربات (برای لینک دعوت) |
| `DB_PATH` | خیر | مسیر دیتابیس |
| `TELEGRAM_PROXY` | خیر | پروکسی تلگرام — برای اتصال بدون VPN |
| `TELEGRAM_PROXY_LIST` | خیر | چند پروکسی پشتیبان، جداشده با کاما |

### 🔌 اتصال تلگرام بدون VPN (اختیاری)

اگر می‌خواهید ربات به تلگرام هم وصل شود ولی VPN ندارید، در `.env` یک پروکسی بگذارید:

```ini
TELEGRAM_PROXY=http://127.0.0.1:8080
# یا چند تا (به ترتیب امتحان می‌شوند):
TELEGRAM_PROXY_LIST=http://p1:8080,http://p2:3128
```

فرمت‌ها: `http://host:port` • `http://user:pass@host:port` • `socks5://host:port`
(برای SOCKS5: `pip install "httpx[socks]"`)

> ✅ **مهم:** اگر پروکسی کار نکند، **فقط تلگرام غیرفعال می‌شود** و ربات بله کاملاً سالم ادامه می‌دهد.
> دیگر خطای `asyncio.CancelledError` کل ربات را نمی‌خواباند.

> 🆔 آیدی عددی خودتان را نمی‌دانید؟ ربات را اجرا کنید و دستور `/myid` را بزنید.

### ۴. اجرا

```bash
python bot.py          # لینوکس / مک
py -3.11 bot.py        # ویندوز
```

اگر همه‌چیز درست باشد:

```
✅ دیتابیس SQLite آماده است: data/bot.db
داده‌ها بارگذاری شدند — دوره‌ها: 0 | کاربران: 0 | ...
✅ ربات روشن شد!
```

حالا در بله به ربات خود `/start` بدهید. 🎉

## 🧪 چک‌لیست تست اولیه

بعد از اجرا این‌ها را امتحان کنید:

| # | تست | انتظار |
|---|---|---|
| ۱ | `/start` در پی‌وی | درخواست اشتراک شماره تماس |
| ۲ | ارسال شماره با دکمه | پیام خوشامد + کیبورد پایین صفحه |
| ۳ | `/myid` | نمایش آیدی عددی شما |
| ۴ | دکمه «👑 پنل مدیریت» | پنل ادمین (اگر آیدی‌تان در `ADMIN_IDS` باشد) |
| ۵ | پنل → «📚 مدیریت دوره‌ها» → دوره جدید | ساخت دوره و افزودن سرفصل |
| ۶ | پنل → «👥 مدیریت کاربران» → یک کاربر → «🔐 محدودیت بخش‌های اختصاصی» | انتخاب یک بخش، بعد **تایپ عدد ساعت** (مثلاً `24`) یا کلمه `دائم` — ✅ **باگ رفع‌شده در دور ششم** |
| ۷ | پنل → «📣 مرکز پیام‌رسانی» | آمار اعضا + چهار مسیر ارسال |
| ۸ | پنل → «💵 درخواست‌های نقدی» | لیست درخواست‌ها |
| ۹ | پنل → «⚙️ تنظیمات عمومی» → «🌐 مدیریت پلتفرم‌ها» | فقط **تلگرام** (روبیکا/ایتا حذف شدند) |
| ۱۰ | تلگرام → «🟢 فعال کن» | در لاگ: `✅ تلگرام فعال شد.` |
| ۱۱ | تلگرام → «📊 بررسی وضعیت واقعی اتصال» | وضعیت واقعی + نام پروکسی |
| ۱۲ | تلگرام → «🔴 غیرفعال کن» | در لاگ: `📴 تلگرام غیرفعال شد.` |

## 🗂 ساختار پروژه

```
bot-Edu/
├── .env                    ← 🔐 شما می‌سازید (در گیت نیست)
├── .env.example            ← نمونه برای کپی کردن
├── requirements.txt
│
├── bot.py                  ← نقطه ورود
├── db.py                   ← جدول‌های SQLite
├── config.py               ← تنظیمات (.env) + داده‌های جهانی
├── core.py                 ← منطق کسب‌وکار
├── ui.py                   ← کیبوردها و صفحات
├── platform_runtime.py     ← کنترل زندهٔ اتصال تلگرام
├── handlers_admin.py       ← کمکی‌های ادمین
├── handlers_messaging.py   ← مرکز پیام‌رسانی
├── handlers.py             ← هندلرهای تلگرام
│
├── GUIDE.md                ← 📘 مستندات کامل
├── DEAD_CODE_REPORT.md     ← گزارش تحلیل کد مرده
└── data/bot.db             ← دیتابیس (خودکار ساخته می‌شود)
```

**زنجیره import (هرگز نشکنید):**
```
db → config → core → ui → platform_runtime → handlers_admin → handlers_messaging → handlers → bot
```

## ❓ رفع مشکلات رایج

| خطا | راه‌حل |
|---|---|
| `❌ توکن ربات پیدا نشد` | فایل `.env` نساخته‌اید یا `BOT_TOKEN` خالی است → قدم ۳ |
| `ModuleNotFoundError: dotenv` | `pip install -r requirements.txt` |
| `ModuleNotFoundError: telegram` | `pip install python-telegram-bot==20.7` |
| خطای `__slots__` هنگام اجرا | پایتون ۳.۱۴ دارید → با ۳.۱۱ اجرا کنید |
| ربات جواب نمی‌دهد | توکن اشتباه/منقضی است → از BotFather بله توکن جدید بگیرید |
| `⚠️ اتصال به تلگرام ممکن نشد` | طبیعی است اگر پروکسی/VPN ندارید. **بله سالم کار می‌کند.** برای رفع: `TELEGRAM_PROXY` را در `.env` تنظیم کنید |
| تلگرام «فعال» است ولی وصل نیست | «📊 بررسی وضعیت واقعی اتصال» را بزنید؛ اگر پروکسی لازم است تنظیمش کنید |
| «شما دسترسی ندارید» در پنل ادمین | آیدی عددی‌تان در `ADMIN_IDS` نیست → `/myid` بزنید و در `.env` بگذارید |

> 📖 جدول کامل‌تر خطاها در `GUIDE.md` بخش ۱۷.

## 💾 پشتیبان‌گیری

همه داده‌ها در `data/bot.db` است:

```bash
# ربات را متوقف کنید، سپس:
cp data/bot.db backup_$(date +%F).db
```

اگر ربات در حال اجراست، فایل‌های `bot.db-wal` و `bot.db-shm` را هم کپی کنید.
